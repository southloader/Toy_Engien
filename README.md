# Toy Engine Prototype

게임 엔진의 기본 구조를 이해하기 위해 개발 중인 토이 엔진 프로젝트입니다.

## 목표

* 엔진의 update loop 구조 이해
* UI 요소 식별 구조 설계
* 입력 처리 및 객체 관리 구조 실험
* 유지보수 가능한 코드 구조 학습

## 내가 고민한 부분

* 엔진 사용자와 개발자가 UI 요소를 직관적으로 다룰 수 있도록 id 기반 식별 구조를 구상했습니다.
* 단순 기능 구현보다 내부 구조와 확장성을 이해하는 데 초점을 두었습니다.

## 사용 기술

* 사용 언어: C++
* 개발 환경: vs code, gnu 
* 현재 진행 상태: Game state 설정
